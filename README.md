# 🚀 Projetos em React / Tailwind / API

Este repositório reúne diversos projetos e exercícios desenvolvidos durante minhas aulas de **programação web**, com foco no ecossistema **React**, **Tailwind CSS** e **integração com APIs**.

O objetivo principal é documentar meu aprendizado e evolução no desenvolvimento front-end moderno, explorando conceitos práticos que vão desde os fundamentos até a criação de aplicações completas.

---

## 🧠 Objetivos de Aprendizado

Durante o desenvolvimento desses projetos, os principais objetivos foram:

- 📘 **Explorar o React**: compreender o funcionamento de componentes, props, estados e hooks.  
- ⚙️ **Praticar TypeScript**: aplicar tipagem estática para aumentar a confiabilidade do código.  
- 💾 **Criar CRUDs completos**: implementar operações de criação, leitura, atualização e exclusão.  
- 🌐 **Consumir APIs**: realizar requisições HTTP com `fetch` e `axios`.  
- 🎨 **Aprimorar o design com Tailwind CSS**: desenvolver interfaces responsivas e modernas.
